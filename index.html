SoloPoster Hub

A personal tool for one creator.

What it does

SoloPoster Hub is a personal productivity tool that helps a single creator send their own videos from a computer to their own TikTok account as drafts. The creator then reviews, edits and publishes each draft inside the TikTok app.

How it works

The creator signs in with TikTok and gives permission. The tool then uploads the video file the creator chooses to the creator's TikTok inbox as a draft, using TikTok's official Login Kit and Content Posting API (Upload). Nothing is published until the creator publishes it in the TikTok app. Access can be removed at any time in TikTok's settings.
